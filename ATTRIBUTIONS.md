## 1. Academic & Pedagogical References
* **Gagne’s Nine Events of Instruction:** Applied as the core instructional design model to structure the learning paths and feedback mechanisms.
* **Networking Fundamentals Content:** Question bank and theoretical concepts were adapted from standard Computer Education and Instructional Technology curriculum.

<a name="2-code-libraries--frameworks"></a>
## 2. Code Libraries & Frameworks
* **Vite:** Used as the frontend build tool for fast development and optimized production builds.
* **Shadcn UI & Tailwind CSS:** Utilized for building accessible, modern, and responsive user interface components (`default_shadcn_theme.css`).
* **JavaScript (ES6+):** Core game engine and state management logic.

<a name="3-uiux--design-assets"></a>
## 3. UI/UX & Design Assets
* **Design System Inspiration:** The gamification mechanics, progress bars, and health systems were heavily inspired by the **Duolingo** app's user experience.
* **Figma:** Initial wireframing and prototyping of the user interface.
